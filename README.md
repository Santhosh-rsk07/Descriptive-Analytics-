# Descriptive Analytics Project

## Overview

This project demonstrates basic **Descriptive Analytics** using Python.
It analyzes student marks data and visualizes the results using charts and plots.

## Features

* Calculate Mean
* Calculate Median
* Calculate Mode
* Calculate Standard Deviation
* Generate Statistical Summary
* Create Bar Chart
* Create Histogram
* Create Box Plot

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Installation

Install the required libraries using:

```bash
pip install pandas numpy matplotlib seaborn
```

## How to Run

Run the Python file using:

```bash
python descriptive_analytics_.py
```

## Sample Dataset

The project uses a simple student marks dataset:

| Student | Marks |
| ------- | ----- |
| A       | 75    |
| B       | 80    |
| C       | 85    |
| D       | 90    |
| E       | 95    |

## Output

The program generates:

* Statistical analysis results
* Bar chart visualization
* Histogram distribution
* Box plot analysis
